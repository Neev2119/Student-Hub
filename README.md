# StudentHub

StudentHub is a responsive student portal website designed to help students manage academic life in one place. It brings together key student features such as dashboard summaries, attendance tracking, course information, assignment updates, timetable access, FAQ support, and contact information in a clean and modern interface.

## Overview

This project is a front-end academic portal built for student convenience. It helps users quickly monitor their academic progress, stay informed about deadlines, and access essential campus resources without navigating multiple disconnected pages.

## Features

- Student dashboard with summary cards
- Attendance overview with subject-wise progress
- Assignment tracking with upcoming deadlines
- Course information and study overview
- Timetable and academic planning section
- FAQ and support information
- Contact and feedback pages
- Mobile-friendly responsive layout
- Login and registration screens

## How to Run

Since this is a static website, you can run it by opening the project in a browser.

### Steps

1. Open the project folder in VS Code.
2. Open [pages/index.html](pages/index.html) in your browser.
3. If needed, use a browser extension such as Live Server for preview.

## Notes

- This is a front-end prototype and does not include a real database or backend authentication.
- It is intended for UI/UX demonstration and academic project work.
